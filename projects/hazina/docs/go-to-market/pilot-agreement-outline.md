# Pilot outline (to be turned into an agreement by a lawyer; not legal advice)

- **Scope:** one SACCO or lender, 60 days, real member book imported, Hazina used alongside the existing books (not instead of them) for the first 30 days.
- **Price:** free for the pilot, then the provisional plan if they continue. No lock-in.
- **Data:** the organisation owns its data; export on request; deletion on request after the pilot. Hazina acts as a processor of personal data; registration with the Data Protection Commissioner as a processor is for Kennedy to check before the pilot starts (not researched).
- **What is promised:** the features in the README; written bug fixes within an agreed time. **Not promised:** regulator acceptance of any output, live M-Pesa before Safaricom setup is done, audit sign-off.
- **Success measure (agree up front):** their books balance to Hazina's ledger at the end of month 1; unmatched paybill payments cleared weekly; arrears list used by the loan officer.
- **What the pilot must produce for Hazina:** a real Safaricom statement and a real paybill confirmation to test against (anonymised if needed), their actual return format if they file one, and a quotable outcome if they are willing.
